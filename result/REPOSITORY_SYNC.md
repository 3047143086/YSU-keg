# 实验仓库同步约定

用户于 2026-10-10 明确授权将当前实验推送至
https://github.com/3047143086/YSU-keg.git，并在有进展时更新。

本地发布仓库为工作区下 `YSU-keg/`，主分支 `main`。
它是可分享文件的精确快照，原有各实验的独立 Git 仓库和冻结文件保持原位。
使用 `python YSU-keg/tools/sync_snapshot.py --workspace .` 更新快照。
查看变更后，在已完成实验、技术失败归档、重要实现冻结或训练启动节点提交并推送。
没有实质进展时不制造空提交。失败证据须保留；未完成任务须标为进行中。

数据、权重、原始评论、连接凭据、飞书访问材料和嵌套 `.git` 不发布。
`SOURCE_MANIFEST.json` 记录每个导出文件的 SHA256 和各局部实验版本。
首次发布和每次更新后，用 `git ls-remote origin refs/heads/main` 核对远端提交。
本约定授权后续任务沿用，不需要再次请求推送许可。
