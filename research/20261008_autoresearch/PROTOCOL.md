# 目标交互隔离的多模态学习：第一轮机制实验

冻结日期：2026-09-10。工作假设，不声称已取得提升或首次提出目标边删除。

## 问题与候选贡献

BRIDGE 将训练矩阵 R 的 ItemKNN 行为证据加入多模态编码器的评分。
虽然物品相似矩阵对角线已经置零，训练正例 (u,t) 仍会通过
`(R.T @ R)[t,h]` 给用户历史中的其他物品 h 贡献一次共现。预测未见物品时
没有这个目标交互的贡献。假设：这种训练目标自支持使协同行为校正过于容易，
影响多模态编码器学到可泛化的偏好。

本次只改变训练期间行为证据的计算；编码器图、原始图像/文本、模型参数量、
损失权重、负采样、推理路径均保持一致。扣除的是已知训练目标对历史、
共现计数、目标物品流行度的贡献。它不是测试标签泄漏，也不是因果曝光估计。

设原始余弦 ItemKNN 矩阵为 S，固定其 Top-K 支持 M，d 为物品训练度数，
原始用户行为分数 b = R[u] @ S.T。对训练边 (u,t)：

- 非目标物品 j：`b_cf[j] = b[j] - S[j,t]`。
- 目标 t：`b_cf[t] = sqrt(d[t]/(d[t]-1)) * (b[t] - sum_h M[t,h]/sqrt(d[t]*d[h]))`，
  h 属于用户剩余训练历史；d[t]=1 时目标分数为零。
- 每个目标对应的全物品均值、方差也同步重算，用列和、列平方和与稀疏点积解析计算，
  避免对每条训练边重建完整物品图。

这个公式只在**固定原始 KNN 支持**的条件下等价于删除目标边后重算统计，
不宣称等价于重新筛选全部 KNN 邻居，也没有删除编码器中的目标边。

## 文献定位

- [AMUR，CIKM 2026，2026-08-28 预印本](https://arxiv.org/abs/2608.27950)：
  选择性模态—兴趣对齐及图细化已是近期研究方向，故不再添加同类路由或对齐权重。
- [SpotTarget：Pitfalls in Link Prediction](https://arxiv.org/html/2306.00899)：
  已研究目标边存在造成的训练与预测差异，采用目标边移除；不能声称首次发现目标边捷径。
- [FakeEdge](https://proceedings.mlr.press/v198/dong22a.html)：通过焦点边处理缓解连接模式差异。
  需要与这里对预计算共现统计的逐目标解析更新区分。
- [EASE，WWW 2019](https://arxiv.org/abs/1905.03375)：对角线约束是已有方法，
  本次检验的是清零对角线后仍存在的非对角共现贡献。

只有计算方法、跨模型证据和多模态作用分析共同成立，才有进一步发展为论文贡献的理由。
如果改善仅来自通用协同过滤修正，不能将其解释成已经证明的多模态独有创新。

## 第二轮：软目标隔离复验

第一轮 Baby 的完整扣除在 R@20/N@20 上升，但 R@10 超过预设回退门槛，
因此不继续 Sports，改做一个预先固定的单变量复验。软隔离在训练正负样本的
标准化行为分数上使用
`z_soft = z_original + 0.5 * (z_edge - z_original)`，正负项使用相同的固定强度
`alpha=0.5`。它不改变推理、候选集、编码器、损失、参数量或数据划分，
也不扫描 alpha；alpha=0 和 alpha=1 仅作为实现退化测试。

软隔离仍以原 BRIDGE 和 history-only 为对照，使用相同的验证门槛：R@20/N@20
相对提升至少 0.5%，R@10/N@10 绝对回退不超过 0.0002，并严格优于 history。
若 Baby 复验通过，再在相同协议下运行 Sports；否则关闭该候选。该轮仍为单种子
探索，不能据此声称稳定提升或论文结论。

## 先做训练集诊断

只读取 x_label=0 的交互作为统计输入，不使用验证/测试标签挑选阈值。
为每条训练正例抽取一个确定性、未观察到的训练负例，随机数生成器独立 seed=2026。
负例排除用户所有已知训练正例，而不按验证/测试标签过滤。

只有以下条件同时成立，才允许该数据集进入训练：

1. 原始正例行为分数均值与扣除后均值之差，除以原始均值，至少为 10%。
2. 至少 25% 训练正例的“仅删历史”标准分减“完整扣除”标准分达到 0.10。
3. 原始缓存与 BRIDGE 原始实现评分的最大绝对差不超过 0.0002，解析式的独立重建测试通过。

这些是机制检查，不是推荐准确率提升证据。失败就停止，不搜索阈值补救。

## 固定实验组与顺序

| 实验组 | 训练历史证据 | 共现与流行度 | 验证/推理 |
|---|---|---|---|
| baseline | 原始 | 原始 | 原始 BRIDGE |
| history | 移除当前目标历史项 | 原始 | 原始 BRIDGE |
| edge | 移除当前目标历史项 | 扣除该训练边贡献 | 原始 BRIDGE |

使用 [默认基线](../../result/DEFAULT_BASELINE.md) 的现有数据和特征，模型从头初始化。
第一轮固定 seed=2026；每组最多 300 epoch、stopping_step=20、batch=2048、
eval_batch=64，按四位小数验证 R@20 严格改善保存 checkpoint，平局保留较早模型。
各组使用独立但相同的种子初始化；新模块不引入可学习参数或随机采样。

先执行数学/协议测试和 Baby 机制诊断；通过后做三组一轮完整冒烟训练，
再从头运行 Baby 三组正式筛选，顺序为 edge、baseline、history。冒烟结果不用于选型或论文报告。
只有 Baby 筛选通过，才进入 Sports 机制诊断、冒烟和相同三组独立验证。

继续条件：edge 相对 baseline 的验证 R@20、N@20 均提升至少 0.5%，
R@10、N@10 的绝对回退均不超过 0.0002；同时 edge 的 R@20、N@20
均严格高于 history 对照。若任一数据集不满足就关闭本轮，不扫描超参数。
保存逐用户指标、成对差值和 2000 次用户 bootstrap 区间；同一验证集的选型和区间
仅作探索性报告，不当作独立确认或多种子显著性。

本轮最多六个正式单种子任务，最多六个一轮冒烟任务。通过后仍需五个固定种子、
第三数据集、ID-only 对照、同幅度非目标缩减对照及模态依赖诊断；本轮不宣称已完成这些。
新入口只构造训练、验证加载器，从不调用会评测试集的原 Trainer.fit。

## 资源和停止规则

只使用既有 Conda MMRec 与既有数据。将代码复制到独立实验目录，复用数据文件；
既有检查点和其他进程不改动。一张 GPU 上顺序运行一个任务，CUDA 显存上限 55%，
启动前要求至少 14 GiB 空闲显存，不要求其他 GPU 任务结束。
CPU 四线程；CPU 缓存采用 float64 统计，原始分数矩阵约为 Baby 1.10 GB、Sports 5.23 GB，
不增加 GPU 上模型参数或推理缓存。单个正式任务最长 8 小时，总流水线最长 48 小时；达到限额明确记为技术未完成。
任何数学测试、有限值、检查点复算或输入哈希检查失败都停止，不把技术失败当作方法无效。
流水线离开当前会话后仍保存进度、日志和最终汇总。
